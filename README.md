# Русификатор для Genotype (VR)

Полный текстовый перевод на русский язык для научно-фантастической VR-игры **Genotype** (Steam / Demo).

## ✨ Особенности перевода
* Переведен весь значимый текст из всех игровых таблиц (сюжетные диалоги, интерфейс, описания био-существ GRAID, задачи и подсказки, экраны загрузки).  
* Перевод выполнен с учётом контекста и лора игры, без машинных обрывков и сломанных тегов.
* Внесены некоторые ручные правки.
* Полностью адаптированы кириллические шрифты для комфортного чтения в VR-шлеме.
* Не изменяет оригинальные файлы игры — работает поверх через BepInEx и XUnity.AutoTranslator, устойчив к проверке целостности файлов и патчам в Steam.
* Совместим как с **полной версией игры**, так и с **демоверсией (Genotype Demo)**.

## 🛠 Установка
1. Откройте корневую папку с установленной игрой:
   * В Steam нажмите правой кнопкой мыши по игре → **Управление** → **Посмотреть локальные файлы**.
2. Распакуйте всё содержимое архива `GenotypeRus.zip` в папку с игрой (туда, где находится `Genotype.exe`, с заменой при необходимости).
3. Убедитесь, что в настройках самой игры выбран **английский язык (English)**.
4. Запустите игру в VR.

---

## 🗑 Удаление
Чтобы полностью удалить русификатор, удалите из корневой папки игры:
* папку `BepInEx`
* файл `winhttp.dll`
* файл `doorstop_config.ini`
* файл `arialuni_sdf_u2019`
